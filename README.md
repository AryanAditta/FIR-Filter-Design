# FIR Filter Design Using Windowing Techniques

**MATLAB implementation and analysis of finite-impulse-response filters using multiple classical window functions.**

This project studies the design of low-pass, high-pass, band-pass and band-stop FIR filters and compares their behavior under different windowing techniques. The workflow includes coefficient generation, frequency-response analysis and audio-signal filtering.

## Implemented Filter Types

- Low-pass FIR filter
- High-pass FIR filter
- Band-pass FIR filter
- Band-stop FIR filter

## Windowing Methods

- Rectangular
- Hann
- Hamming
- Blackman

## Analysis Performed

- Filter-coefficient generation
- Magnitude and frequency-response analysis
- Impulse-response inspection
- Pole-zero visualization
- Audio-signal filtering experiments

## Repository Contents

- [`main_filter_design.m`](main_filter_design.m) — main MATLAB workflow for filter design and analysis.
- [`filter_coefficient.m`](filter_coefficient.m) — coefficient-generation support code.
- [`2.wav`](2.wav) — audio sample used for filtering experiments.
- [`DSP Open-ended Report.pdf`](DSP%20Open-ended%20Report.pdf) — project report.

## Running the Project

1. Open the repository in MATLAB.
2. Ensure `main_filter_design.m`, `filter_coefficient.m` and `2.wav` are in the active working directory.
3. Run `main_filter_design.m`.
4. Inspect the generated filter responses and audio-processing outputs.
